# Personal website

Source of the personal website of Marston H. D. Franceschini, published by GitHub Pages at https://mhdf.github.io.

- `index.html`: the page (about, research themes, publications, software, experience and education, contact);
- `assets/style.css`: the layout, with light and dark themes;
- `assets/site.js`: the theme button and the filters of the publications.

The site is plain HTML: nothing to build. To add a publication, copy one `<li>` of the list in `index.html` and change
it; its `data-themes` (disease, uav, crop, soil) decide the filters it appears in.

The site was written with the help of an AI coding assistant (Claude, by Anthropic). The author directed the work, checked the content and is responsible for it.
